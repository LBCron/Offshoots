Editorial handbook

Making a class

Lineage and numbering

Use the Atlas for direct parent and child connections. Course numbers follow the primary musical lineage. Where influences are genuinely shared, describe them without inventing a single parent. Keep the first two number levels as written and drop leading zeroes from subsequent levels. Put one space between the number and genre title, then a middle dot before the subtitle.

Research and selection

Start with a listening question and a change a listener can hear. Verify original release dates, the artist and recording credits, and the scene or technology where it matters. Compare candidates before selecting. When the available examples start to repeat, search further across artists, labels and eras. Each track earns its place by teaching something. There is no track quota.

Sequence and package

Use chronology as the spine. Give roots enough room to make the later change audible. Consider transitions, pacing and the ending. Package the numbered title, description and ordered list separately. Format import tracks as Artist - Song, one per line.

Descriptions

Keep the public description to one line and 300 characters. Start with the active period, then describe what the music sounds like. Use FROM: and LED TO: for up to three direct connections each. Omit the latter when the map gives no direct descendants. Keep extended teaching notes separately.

Publish and verify

  1. Check titles, credits, exact versions and order in Apple Music first. Prefer the original recording on its original release where available. A remaster or archival issue can carry the same original recording.
  2. Publish the Apple Music list, then copy it to Spotify via Soundiiz. Verify the destination counts, order, versions and public links.
  3. For corrections, verify additions before removing the old playlist entries. Keep the existing playlist identity and document any service differences.
  4. Update the curriculum workbook, then save a text and JSON app manifest with the node ID, title, links, description, art availability, artist credits and ordered tracks for each service.
